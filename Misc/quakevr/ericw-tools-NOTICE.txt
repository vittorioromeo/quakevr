ericw-tools' light, shipped with Quake VR for the in-game relighting
====================================================================

The files in this folder (light.exe, embree4.dll, tbb12.dll, tbbmalloc.dll) are light from ericw-tools
2.0.0-alpha11-qvr1, Quake VR's fork of ericw-tools 2.0.0-alpha11, and the libraries it needs:

    https://github.com/vittorioromeo/quakevr/releases/tag/assets-2026-11-17
    (ericw-tools-2.0.0-alpha11-qvr1-win64.zip)

The fork changes only light: deterministic lightmap packing (two runs write the same bytes) and the option
-bounceextra (the bounced light traced from fewer samples: about twice as fast, the look nearly the same). Without
-bounceextra it lights exactly as ericw-tools 2.0.0-alpha11. Its README.md says more. The DLLs are those of
ericw-tools' own 2.0.0-alpha11 Windows release, unchanged.

Quake VR runs light.exe as a separate program (VR Settings > Advanced VR Options > Graphics > Relighting), giving it
a copy of a map and reading the files it writes. It is not linked into Quake VR, and Quake VR does not depend on it
to run: delete this folder and the game works as before (only the in-game relighting needs light, and it can be
pointed at another copy with vr_relight_tool).
