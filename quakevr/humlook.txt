# reads it again, vr_humlook_info prints what the nearest armed humanoid wears. Phase 2's Texture Studio writes it.

# A row: <type> <category> <part>, then 13 numbers.
#   type      grunt, enforcer, knight, dknight (the armed monsters' rows, QC VR_AM_*)
#   category  explosive (rockets, grenades), energy (lightning, plasma, lasers), flame, poison; the others (shells, nails,
#             melee, the monster's own gun) have no row: as today
#   part      clothes (its body's skin), pack (its worn backpack)
# The pixels it changes (a range of the skin's colours, soft at its edges):
#   hue        the range's middle hue (degrees)
#   width      half its width (degrees; 180: every hue)
#   feather    the soft edge past it (degrees)
#   satmin     the least saturation counted (0..1: greys below it are left)
#   lightmin   the least and the most lightness counted (0..1)
#   lightmax
# What it does to them (HSL), then a tint (the colour multiplied in, by `amount`: for near-white skins):
#   shift      the hue turned by this (degrees)
#   satmul     the saturation times this
#   lightmul   the lightness times this
#   tint r g b amount
#
