// `kind <name> { <part> { key "value" ... } ... }`. Kinds: grunt, enforcer, knight, death_knight, player (every vrbody
// build), or a model's path ("progs/vrbody_bare.mdl", over its kind's). Parts: cuirass, helmet, pauldron, bracer, thigh,
// shin, each limb part's sleeve over its joint (pauldron_sleeve, bracer_sleeve, thigh_sleeve, shin_sleeve). A limb part
// is both sides, mirrored (the left's values; the right's the mirror image); <part>_l or <part>_r one side's own, over it.
//   offset   "x y z"   units along the model's forward, left and up (its rest pose)
//   rotate   "p y r"   degrees about the model's left, up and forward axes, round the piece's middle
//   scale    "s"       its size round its middle (1 as made)
//   standoff "u"       units further off the skin (below 0 closer)
//   start    "u"       units its first row of plates starts further along it (towards the waist, hand or foot)
//   end      "u"       units its last row ends further along it
//   rows     "n"       its rows of plates (0 the generator's; the cuirass counts its collar row)
//   taper_start "s"  the plate rows' size round its line at its first row (1 as made), lerped row by row to ...
//   taper_end   "s"  ... this at its last row (a thigh wider at the hip, narrower at the knee: 1.15 and 0.9)
//   leather  "0"       a sleeve's leather not drawn at all (1 or unset: drawn)
//   hero     "0"       its hero plates off, every plate its own (1 or unset: the breastplate, the pauldrons' top row,
//                      the elbows' and knees' cops each one plate over several columns; vr_agarmor_hero 0: off everywhere)
// (start, end, rows and the tapers: the cuirass and the limbs' plates; not the helmet or the sleeves; leather: the sleeves)
