// quakevr/data/groups.txt -- the monster groups' values: read at start into the group table (Quake/vr/vr_mgroups.cpp;
// the groups, their labels and members: vr_mgroups.inc, vr_mgroups.cpp; the keys: vr_mgroups.hpp Param). Each value is
// reached by its old cvar name (vr_mgrp_<id>_<key>; resist: vr_kdtrig_resist_<id>; shove: vr_knockdown_chance_<id>):
// the config, the console, Combat > Monster Groups, the QC. Written once from vr_mgroups.inc's defaults by
// Misc/quakevr/groups_data.py convert; edited by hand since, or by its `promote <config>` (the player's changes, saved
// in the config by the old names, made the defaults).
//
// `defaults { key "value" ... }`: a key's value for a group whose block leaves it out. Then `group <id> { ... }`: its
// values (each its effect before the groups: 1 as it was, 0 never).
//   kdtrig      the ragdoll triggers take it (the humanoids')
//   resist      its resistance to them: every trigger's chance divided by it, its least damage times it; 0: by its size
//   ledge       ... blast, thrown, tackle: each trigger's chance times this (0: never)
//   shove       a shove's base chance to knock it down (only a monster with a get-up of its own)
//   push        how far shoves, bashes and unbalancing hits move it, times this (0: bosses stand their ground)
//   stagger     hits' chance to unbalance it, times this
//   sweep       ... leggrab: the leg sweep, the leg pull and lift take it (the skull wizard's robe has no legs)
//   lift        ... necksnap, manhandle: the lift, the neck snap, grabbing it staggered or weak take it (humanoids)
//   throw       the two-hand throw: 0 never, 1 only when hurt, 2 always
//   hold        one hand's hold on it, 0..1 (-1: by its size)
//   poise       its Parry Poise: a parry's strength over it decides blocked, flinch or stagger; above 1 also the
//               melee's knockdown chances over it; -1 Off: a parry never staggers it (QC combat.qc VR_Parry_Outcome)
//   health      its health times this as it appears (with Monster Health on)
//   kdscale     every chance to knock it down times this (a sure one by this chance too)
//   downtime    its time down times this; getup: its get-up's speed times this
//   snapkills   the neck snap kills it (0: it only hurts, vr_foegrab_necksnap_tough)
//   struggle    held while knocked down, its members with a struggle profile struggle (vr_mgroups.cpp
//               struggleProfiles); their strength, speed and arm drive times struggle_strength, _speed, _arms,
//               weaker as they are hurt (struggle_hurt 1)
