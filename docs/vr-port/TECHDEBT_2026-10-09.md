# Technical debt review (2026-10-09)

Vittorio asked for a sweep of technical debt and outdated information: old hacks, code paths we stopped using,
temporary debug and test features, old or superfluous documentation, unused files, leftovers from the old Quake VR
engine, code kept only for old saves, and profiling code for problems that are already solved. Anything clear-cut was
removed on branch `agent/techdebt`. Anything that needs his judgement is in **Needs a decision** below, each item
with a recommendation.

Earlier passes this builds on: [CVAR_AUDIT.md](CVAR_AUDIT.md), [REPO_CLEANUP.md](REPO_CLEANUP.md) and
[DOCS_REVIEW.md](DOCS_REVIEW.md), all from 2026-10-06. The evidence for every item (grep counts, origin commits) is in
the worktree's `scratch/td/inv_*.md` (not tracked).

**Areas left alone** (other workers were changing them during this sweep): map renaming and map aliases, the toolgun,
menu dialogs, the OpenXR runtime choice and runtime pause, crouch and body, stairs and lava. Ironwail's own code was
also left alone, apart from one comment in `host_cmd.c` on our own addition.

## Needs a decision

Recommendations are in bold. Items are ordered by value.

### 1. Config migration chains (they still update his config)

`vr_cvars.cpp` has 470 `defaultChanges` entries (configs 1..114) and 15 version-gated blocks. Two more chains run
alongside it: `vr_weapons.cpp` (`settingsVersion` 40, `vr_wofs_version`) and `vr_props.cpp` (`settingsVersion` 68,
`vr_props_version`). On top of those come `bodycal::migrate`, the slipgate→teleporter aliases, `retiredCvars`, the
hotspot and cup migrations (`legacyHotspots`, `grasp::legacyGripChannel`, `takeHotspotMigration`), and 28 retired
weapon keys that are still registered (about 900 `vr_wofs_*` cvars) "so that saved configs load silently". His config
is at 114 / 40 / 68.

**Plan:**
1. At the first public release, set a floor version: the release's own versions (e.g. 120 / 45 / 70).
2. On load, a config below the floor keeps only the player-facing settings, using an allow-list (calibration, comfort,
   bindings and the like). Everything else resets to the shipped defaults, with one console line saying so.
3. Delete every `defaultChanges` entry and every `from < N` block below the floor, together with the legacy hotspot
   and cup code and the retired weapon keys. `retiredCvars` would silence those names by pattern.
4. Before cutting, run the release once on his current config, so that his own values move first.

Until the release, keep the chains as they are.
